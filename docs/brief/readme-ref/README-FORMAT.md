# README format reference (self-contained reconstruction)

Model: `https://github.com/ghgoodreau/athanor/blob/main/README.md` and `https://github.com/matiassingers/awesome-readme`.

Required shape for undertow:

1. First line is a 1280x400 banner image.
2. Two or three plain sentences saying what the project is.
3. GitHub topics as hashtags, a small black-and-white flat-square badge row, and a demo GIF/link from a real run.
4. One large real hero screenshot immediately after the intro.
5. Short themed sections: `## The Tide`, `## The Undertow`, `## The Weights`, `## The Results`, `## The Limits`. Each is a few plain paragraphs plus one real black-and-white screenshot or plot.
6. Use a compact 2x2 markdown image grid when useful.
7. `## Install`: one shell block for clone/setup/run, followed by what it touches and how to undo. Document downloads and checksums. No API key.
8. `## The Name`: explain the undertow metaphor literally.
9. `## Inspirations`: link `INSPIRATIONS.md` and closest prior work.
10. `## License`: MIT and third-party terms in `NOTICE.md`.

Palette rules: pure black background, white/grey type and art only. No color accents in banner, screenshots, plots, GIF, badges, or diagrams. Convert color app captures to grayscale for README. Voice: calm, literal, short sentences, a little wit, no hype, no emoji.
